# VTA DwC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 原生 DwC 在同一真实 KWS 层上通过三组配置的 FSIM、TSIM 精确数值验证。

**Architecture:** Opcode 5 复用 GEMM 指令字段和计算流水线。输入按 BLOCK_IN 向量化，通过 min(BLOCK_IN,BLOCK_OUT) 宽度的 banks 提供并行输入；权重从 memory 加载到寄存器，按实际 KH、KW 逐步取最低位并移位。

**Tech Stack:** C++ VTA runtime/FSIM、Chisel/Scala、TVM TE/TIR、Python/NumPy、pytest、Verilator TSIM。

**Spec:** `docs/superpowers/specs/2026-10-09-vta-dwc-design.md`

## Global Constraints

- VTA_OPCODE_DWC=5；复用 GEMM 字段，不增加 ISA 位宽。
- 阵列和流水线复用；DwC 每个 dot-product 仅首个乘法器工作。
- 输入按 BLOCK_IN 向量化，不因 BLOCK_IN/BLOCK_OUT 关系补零。
- 输入总并行宽度 BATCH × max(BLOCK_IN,BLOCK_OUT) × INP_BITS；单 bank 宽度 min(BLOCK_IN,BLOCK_OUT) × INP_BITS。
- 权重按 BLOCK_IN 打包补零，uop 按实际 KH、KW 执行；有效周期消费 BLOCK_OUT 个最低位权重并移位。
- 默认 schedule；同一 KWS 样例覆盖 (8,8)、(8,16)、(16,8)，先 FSIM 后 TSIM。

## Review Focus

- 停顿、依赖等待或 reset 不得意外消费权重；Task 4 检查寄存器状态。
- 同一权重地址用于不同输出位置必须恢复原始权重；Task 2、4 覆盖。
- 负权重取最低位后保持有符号解释；Task 2、4 覆盖。
- 输入跨 bank 和输出子块选择不能依赖未使用 lanes 为零；Task 3、6 覆盖。
- 末尾权重 padding 不产生额外 uop；Task 5 检查 3×3 的九次实际消费。
